## What’s new in 0.5.5

- Search full cluster context names from the sidebar, with keyboard selection, Escape and click-away dismissal.
- Open App catalog, GitOps, Extensions, Connect clusters, API explorer, Change history and Updates & setup from the native macOS File menu. Installed extension pages stay under Extend.
- Services and Ingresses are grouped under Network.
- Nodes and Cluster hide Create resource. Other resource pages retain creation tools.
- Namespace selection applies immediately; the redundant Done button is removed. Click outside the picker to close it.

- HPA and VPA are grouped under More Workloads.
- Node details show assigned Pods across namespaces, with search, refresh and direct Pod details. Permission failures remain visible.
- Connect opens the cluster automatically after a successful connection. Selecting an AWS role prepares its profile and loads EKS clusters automatically; selecting a saved profile loads its clusters too. Browser authentication and account/role choices remain explicit.

- Rapid AWS account/role switches discard stale profile responses before enabling a connection.

This release remains ad-hoc signed and is not Apple notarized. See the installation instructions below for the macOS Open Anyway steps.
