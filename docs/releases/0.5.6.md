## What’s new in 0.5.6

- Large resource tables show 50 rows per page, with Previous/Next controls and 50/100/250 row choices.
- Search, filters, sorting and CSV export cover the full loaded resource list. Changing a filter resets the page; metrics and watch updates retain the current page when possible.
- Persistent API resource lists paint each received page while the remaining pages load, with an explicit loaded/loading count. Old context/request responses are ignored and Secret list data remains redacted.
- Pod, Node, workload/configuration and Events tables use the page controls. Small lists and the grouped CRD view retain their compact layout.

- Pod Containers cells show one compact status square per actual container, including init/debug containers. Hover for the name, state and restart count. Green means ready, amber means starting/not ready, red indicates errors, blue marks completed containers and muted outlines indicate unavailable status.

Pagination and progressive loading improve first paint and table rendering; authentication, discovery and API network latency still depend on the cluster.

This release remains ad-hoc signed and is not Apple notarized. Installation instructions below include the macOS Open Anyway steps.
