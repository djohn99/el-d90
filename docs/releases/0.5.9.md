## What’s new in 0.5.9

- Open the official regional AWS `signin.aws` approval pages returned by IAM Identity Center, alongside existing AWS approval domains.
- Keep HTTPS-only validation, reject embedded credentials and nonstandard ports, and accept official approval pages across AWS regions.
- Explain unsupported browser sign-in addresses instead of showing an unrelated generic AWS CLI error.

Existing AWS role permissions remain unchanged.

Changing SSO region starts a new sign-in for that region. Use the organisation’s IAM Identity Center region; select the cluster location separately under EKS region.
