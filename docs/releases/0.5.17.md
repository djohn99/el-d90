## What’s new in 0.5.17

- Kubernetes API reads request compressed responses to reduce transfer size for large inventories such as Pods and Deployments across all namespaces.
- Resource pagination skips a redundant JSON conversion. The client still honors the kubeconfig compression setting and enforces the response limit after decompression.

GitHub Actions builds, tests, and publishes the Apple Silicon DMG and Windows x64 portable ZIP.
