## What’s new in 0.5.3

### Faster cluster browsing

- Resource lists, metrics/API reads, resource Events and live watches now use persistent Kubernetes API connections with separate credentials and connection pools for each context.
- Warm namespace reads in a live read-only check took about **150–220 ms**, compared with about **840–1,050 ms** through kubectl. First authentication still took about one second; results depend on the cluster and network.
- Optional metrics no longer block resource rows or navigation. Paginated reads, cancellation and watch reconnect/relist handling support large lists and changing clusters without mixing results.

### AWS SSO: choose your account and role

- Sign in through your AWS access portal, then discover the accounts and roles assigned to you.
- Search and click an account and role inside el-d90. Each selection gets its own named profile and EKS connection without copied tokens or manual update-kubeconfig commands.
- Reopen the browser approval page from the app if needed. Existing IAM and Kubernetes permissions remain unchanged.

### Better resource details and workspace tools

- View Secret values with per-key reveal/hide/copy controls and stage edits in YAML. Inspect and edit ConfigMap text and binary keys with preserved drafts and YAML review.
- Use resource-specific details, container status/resources, annotations and linked references. HPA/VPA navigation includes recommendations and unavailable-API states.
- Group the resource map by namespace, application or node; collapse groups, follow dependencies and use breadcrumbs. Projects combine selected namespaces across contexts while retaining cluster identities and partial-coverage warnings.
- Use the optional local Monaco YAML editor, side-by-side change review, baseline reset, diagnostics and guided resource forms. The plain editor remains available.
- Browse a curated Helm catalog and inspect Argo CD/Flux resources in read-only GitOps views. Local declarative extensions can add resource pages, detail sections, columns and map relations.
- Import kubeconfig paths with connection/provider diagnostics. Sidebar headings are bolder; Advanced and Custom API Groups collapse. Appearance saves preserve newer previews while an earlier save completes.

### Validation and compatibility

- **226 backend checks and 24 packaged desktop acceptance suites passed**, covering API reads/watches, permission isolation, terminals, logs, Helm, resource editing, settings and workspace navigation.
- Live read-only role checks: AdministratorAccess loaded 16 Ready nodes and node metrics; EditOnlyAccess loaded 23 namespaces and correctly received Forbidden for Nodes. Both connected staging Pod watches and listed staging Helm releases. No role permissions or cluster resources were changed.
- Interactive terminals, logs, port forwarding, Helm, YAML apply/validation and mutations retain their existing CLI paths. Resource lists continue to redact Secret values and sensitive annotations.
- Historical charts require compatible Prometheus data; current metrics require the Metrics API and appropriate permissions. AI remains deferred.
- Apple Silicon, macOS 13+. The installer remains **ad-hoc signed, without Apple Developer ID signing or notarization**. Follow the installation and Open Anyway instructions below.
