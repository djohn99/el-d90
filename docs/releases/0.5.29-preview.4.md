## What’s new in 0.5.29-preview.4

Preview for testing on another Mac

This is a test build; no GitHub release has been created.

- Automatically use macOS-trusted company and public CA certificates for AWS CLI, EKS credential generation, and AWS SSO. Existing CA bundle overrides remain available.
- Report safe, specific credential-plugin errors without exposing raw plugin output or tokens.
- Request 10,000 initial log lines, browse retained history in smaller pages, and download filtered history with icon-only buttons.

On the affected Mac, open AWS SSO → EKS and retry the connection. If IT recently installed a trusted certificate, use Refresh automatic settings. A CA that is not trusted by macOS still requires a trusted installation or an explicit CA bundle.

- Distinguish credential-plugin failures from kubeconfig TLS and token-file setup errors. AWS diagnostics can test EKS token generation directly without displaying credentials.

- Acknowledge app-owned kubeconfig changes in the folder watcher so the next poll does not cancel a newly started credential provider. Discard stale polls that overlap managed source updates.

- Keep AWS account, role, region and namespace dropdowns attached while scrolling; dismiss other floating menus when their page moves.
- Place namespace guidance below the field in the accent color.
- Connect to multiple namespaces entered with commas or spaces, deduplicate entries, and check access to each before opening the workspace. Single-namespace connections remain supported.
