## What’s new in 0.5.4

### AWS connections on managed Macs

- el-d90 now imports exported proxy, CA bundle and AWS config paths from your login shell when launched normally from Finder, and prefers the AWS executable resolved by that shell. Startup import is bounded and excludes static AWS credentials.
- Under **Advanced → Connect clusters → AWS executable & proxy settings**, optionally choose an AWS CLI executable, HTTPS proxy, bypass hosts or company CA bundle. Blank fields use automatic settings. These settings apply to AWS CLI requests and EKS token environments; re-add an EKS connection after changing its executable.
- **Check AWS connection** shows the executable, CLI version, selected profile/region, and sanitized identity/EKS results. It does not return raw credential payloads or proxy passwords.
- Configured AWS endpoint URLs are respected. TLS certificate verification remains enabled. Configure a trusted company CA bundle if your proxy requires it.

The corporate-proxy changes passed offline regression checks, and live EKS discovery worked on the development Mac. The connection on the affected second Mac still needs verification. If loading clusters fails there, use **Check AWS connection** and share its sanitized result.

### Tables and namespace controls

- Drag a column’s right edge to resize it. A thin highlight appears only on hover, keyboard focus or drag. Widths are saved separately for each resource type.
- Focus a divider and use the arrow keys to adjust it; Shift makes larger adjustments. Double-click resets its width.
- Resource pages use compact headers, bringing the namespace selector and actions closer to the filters/table.
- Nodes and other cluster-scoped resources hide irrelevant namespace controls. The repeated All namespaces line is hidden; selected namespace chips remain removable.

### Installation

Apple Silicon Mac, macOS 13 or later. Open the DMG, drag el-d90 to Applications, eject the image, and launch from Applications. AWS CLI v2 is required for AWS connections; kubectl and the relevant authentication plugins are required for CLI workflows, and Helm is optional for Helm management.

This release remains **ad-hoc signed**, without Apple Developer ID signing or notarization. If macOS blocks it, follow the Open Anyway instructions below or in the README. No credentials, profiles or kubeconfigs are bundled.
