## What’s new in 0.5.4-dev.1

This local preview addresses AWS CLI differences between Terminal and Finder launches.

- Import exported proxy, CA bundle and AWS configuration paths from the user's login shell, with a bounded startup timeout and a strict allowlist that excludes credentials.
- Prefer the AWS executable resolved by that shell, with an explicit executable override under AWS executable & proxy settings.
- Save optional HTTPS proxy, bypass hosts and CA bundle overrides privately on the Mac. Changes affect AWS CLI requests and EKS credential-plugin environments. Re-add an EKS connection after changing its executable.
- Respect configured AWS endpoint URLs and retain TLS verification.
- Check AWS connection reports the executable, CLI version, selected profile/region, and sanitized identity/EKS checks without returning credential payloads.
- Resize resource table columns by dragging header boundaries or using arrow keys. Widths are saved separately for each resource type; double-click resets a column.

The corporate-proxy fix has offline regression coverage. Verification on the affected Mac is still required; this preview does not claim a confirmed resolution there. This build remains ad-hoc signed and is not notarized.
