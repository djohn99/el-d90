## What’s new in 0.5.3-dev.1

This is an unreleased local development build. Published 0.5.2 installers remain unchanged.

- Persistent, isolated Kubernetes API connections for resource lists, metrics/API GETs, resource Events and live watches. Paginated reads, cancellation, credential refresh, TLS verification, namespace isolation and watch 410/403 handling are covered by transport tests. Terminals, logs, port forwarding, Helm and mutations retain their CLI paths.
- Serialized appearance saves prevent an older save result from overwriting a newer preview.
- Searchable, directly clickable SSO account/role lists replace native dropdowns; selected choices remain highlighted, and changing accounts clears the previous role.
- AWS SSO portal sign-in followed by discovery of assigned accounts and roles, separate role profiles, private refreshable CLI caching and unchanged IAM/RBAC permissions.
- Bold sidebar section headings and a fully collapsible Custom API Groups section.
- Browser-owned AWS SSO sign-in, profile setup, EKS region/cluster discovery, manual cluster entry and immediate app-owned kubeconfig registration without copied tokens or global kubeconfig changes.
- ConfigMap multiline text/binary data cards and local key editing with YAML review, preservation of untouched fields and dirty drafts.
- Type-specific details and applicable tabs across built-in resources, container status/resources, annotations and declared reference links.
- Non-blocking optional table metrics, fewer irrelevant permission checks and cross-cluster stale-response regression coverage.
- Per-key Secret show/hide/copy and edit-to-YAML controls with UTF-8 encoding and cleared edit buffers.
- Decoded Secret reveal/hide controls with local-only detail display, binary labelling, and stale-result cleanup.
- Clearly named HPA/VPA navigation, VPA recommendation columns/details and an explicit unavailable-API state.
- Hierarchical map grouping, collapse/expand, dependency focus and breadcrumbs.
- Projects combining explicitly selected namespaces across configured clusters, with partial-coverage health/resource summaries.
- Optional local Monaco YAML editing, side-by-side change preview, baseline reset and local/schema diagnostics.
- Guided forms for common resource kinds and available schemas, synchronized with YAML while preserving fields outside the form.
- Curated Helm application browsing that hands exact chart versions/values to the existing preview and confirmation workflow.
- Read-only Argo CD and Flux dashboards with source/revision/condition information and verified local resource links.
- Declarative extension SDK v1 with local install/update/disable/remove, resource pages, metadata/status detail sections, table columns and map relations. No arbitrary script execution or Headlamp plugin compatibility.
- Guided kubeconfig path import, provider/client diagnostics and read-only connection tests. Configured OIDC exec providers control browser authentication; el-d90 does not collect passwords or register identity-provider applications.

Namespace checkboxes apply immediately, as in the previous release. AI remains disabled. Normal Kubernetes RBAC, monitoring requirements and native mutation confirmations remain in effect. This build remains ad-hoc signed and not Apple notarized.
