## What’s new in 0.5.12

- Public downloads for **Apple Silicon macOS** and **Windows x64**, with SHA-256 checksums and GitHub build provenance. Download directly from this release without signing in to GitHub.
- Fix Windows interactive terminals with Microsoft’s maintained MIT-licensed node-pty and bundled ConPTY support, including native resize handling for resource terminals and saved sessions.
- Retain the 0.5.11 automatic AWS connection settings and per-field manual overrides.

## Validation and limits

Publication waits for both native builds. The macOS job runs 251 backend tests, all 28 packaged desktop suites, and DMG/signature verification. Windows tests the actual packaged native module inside Electron: repeated Command Prompt and PowerShell input, resizing, Unicode output, exit, kubectl.exe discovery, a private context overlay and cleanup, and Monaco YAML editing. Both jobs require a zero-advisory dependency audit.

Fixture tests do not establish live AWS/Kubernetes, SSH or Helm mutation acceptance on every PC. macOS is ad-hoc signed without Apple notarization; Windows is not Authenticode signed. Install platform tools and authentication configuration separately. No credentials are bundled.
