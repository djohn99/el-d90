## What’s new in 0.5.13

- Remove **Explore demo workspace** from the sidebar and **Explore the demo** from the welcome screen in packaged macOS and Windows apps.
- Keep demo controls available when running from source for development. Normal packaged launches cannot enable demo mode; isolated acceptance-test launches retain their fixtures.
- Add packaged demo-visibility checks to the macOS desktop and Windows acceptance suites.

Both the Apple Silicon DMG and Windows x64 portable ZIP are public downloads without GitHub sign-in. Extract the entire Windows ZIP before opening el-d90.exe.

## Validation and limits

The release workflow runs 251 backend tests, 28 packaged macOS suites and native Windows terminal/context/editor checks, including hidden demo controls. Both platforms require a zero-advisory dependency audit before publication. Checksums and build provenance accompany the installers.

macOS is ad-hoc signed without Apple notarization; Windows is not Authenticode signed. Install kubectl, AWS CLI and Helm separately as needed. No credentials are bundled.
