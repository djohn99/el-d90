## What’s new in 0.5.11

- Restore the visible **AWS connection settings · automatic + overrides** panel.
- Reuse exported AWS CLI, proxy and company CA settings from the login shell, with independent per-Mac manual overrides.
- Refresh automatic settings without restarting; retain manual overrides and unsaved form edits. Show each field’s source and provide a saveable return-to-automatic action.
- Normalize uppercase/lowercase proxy variables and isolate shell startup output from environment parsing. If refresh fails, retain previously loaded automatic settings and show a warning.

## Test the connection on another Mac

Open **File → Connect clusters**, expand **AWS connection settings · automatic + overrides**, then choose **Refresh automatic settings**. Set a manual AWS executable, HTTPS proxy or company CA bundle only where needed, and choose **Save connection settings**. Use **Check AWS connection**, then **Load EKS clusters**. Re-add an EKS connection if you changed its AWS executable.

TLS verification remains enabled. A company proxy requires a trusted CA bundle if AWS CLI does not already trust its certificate. Automatic settings import exported shell configuration, not temporary variables in another open Terminal tab, aliases, or command-line flags.

Validation includes 250 backend tests, AWS connection settings UI regression coverage and the packaged macOS acceptance suite in GitHub Actions. The affected corporate-network Mac still requires user verification. Apple Silicon/macOS 13+ only; the DMG is ad-hoc signed, without Apple notarization. Windows publication remains deferred.
