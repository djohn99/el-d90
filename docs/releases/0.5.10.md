## What’s new in 0.5.10

- Fix all seven dependency-advisory package entries. Rebuild the actual Monaco browser runtime with DOMPurify 3.4.17; remove stale prebuilt editor files, retain search/diff/folding/language contributions, and update vulnerable packaging dependencies.
- Publish the Apple Silicon DMG. Windows support remains experimental and is deferred until native acceptance tests pass.
- Load searchable, access-checked namespace choices when selecting an EKS cluster. Clear old role choices when switching profiles; retain a known-namespace fallback for roles that cannot enumerate namespace names.
- Simplify ConfigMap editing with direct Save, Save & Close, optional YAML review and in-memory drafts that survive closing details. Preserve multiline text, binary fields and validation/cancellation feedback.
- Connect resource terminal tabs automatically, reuse active sessions, and start a cluster terminal when opening an empty Terminal & logs panel.
- Use a button-only exact-target confirmation for all resource deletions, including Deployments. Node drain retains its separate confirmation and eviction safeguards.
- Keep Connect clusters as a deliberate File-menu page rather than restoring it automatically; remove duplicate setup controls.

## Validation and limits

macOS backend and packaged desktop acceptance checks, generated-editor sanitizer checks, and a zero-advisory npm audit gate run before publication. Fixtures do not certify live SSH, privileged node-debug or Helm mutations. AWS/Kubernetes role permissions remain unchanged.

The macOS build is ad-hoc signed, without Apple Developer ID signing or notarization. Install only from this repository’s release and verify the provided checksum. Windows downloads are not included in this release.
