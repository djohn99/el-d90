## What’s new in 0.5.7

- Sidebar groups follow Favorites, Cluster, Nodes, Workloads, Config, Network, Storage, Namespaces, Events, Helm, Access Control and Custom Resources. Cluster, Nodes, Namespaces and Events are direct links; other sections collapse and remember their state.
- Connect clusters hides the namespace picker, Refresh and Create resource controls.
- Restore valid AWS CLI SSO cache sessions after restart without opening the browser. Account/role selections return when reopening the connection screen. Tokens stay in the main process and private AWS cache; expiry and assigned roles still apply.
- Match the reference submenu order and labels; autoscaling and disruption budgets are under Config. Add Priority Classes, Runtime Classes, Leases, admission configurations/policies and Ingress Classes, each with scoped API access and resource-specific columns.
- Helm has separate Charts and Releases links. Custom API groups sit directly under Custom Resources. Additional utilities remain in File → Workspace tools.
- Fix an obsolete collapse style that hid custom API groups; verify visible groups, resource navigation and collapse/reopen behavior.

- Preserve a manually selected AWS profile and region if an earlier session restore finishes later.
