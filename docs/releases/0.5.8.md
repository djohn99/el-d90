## What’s new in 0.5.8

- Find floats inside the YAML editor at the top right, with no extra row or editor resizing.
- Find in plain resource YAML, Helm values, kubeconfig settings and dynamically generated data editors with match counts, case sensitivity, next/previous and wraparound.
- Use Edit → Find or ⌘F, with native search in rich YAML and comparison editors, existing log filters, and local terminal scrollback search/highlights.
- Search rendered page text outside editors and sessions. Existing table filtering still spans all loaded pages.
- Escape closes Find before resource details/settings and clears a nonempty log query first. Searches do not apply resources or persist queries.
- Keep literal search match offsets correct after Unicode text.
- Stabilize the terminal-close acceptance check by awaiting process and renderer cleanup.

See the [search audit notes](../qa-search-2026-11-06.md) for tested scope and environment limitations.
